# Outer Bounds Pictures

**Live Site:** https://www.outerboundspictures.com/

A cinematic, modern web experience for **Outer Bounds Pictures**, designed and developed by **Max Karltun**. This repository powers a visually driven brand presence built with Wix Git Integration and enhanced front-end tooling for local development, customization, and deployment.

---

## About the Project

Outer Bounds Pictures is a creative portfolio and business presence focused on visual storytelling, production, and digital presentation. This site was crafted to deliver a sleek, immersive user experience that highlights branding, media, and design with a polished modern aesthetic.

This repository is connected to **Wix Git Integration & Wix CLI**, allowing local development workflows while staying synced with the live Wix-powered site.

### Highlights

- Visually engaging and brand-focused presentation
- Responsive front-end design
- Local development with Git-based workflow
- Real-time testing and publishing through Wix integration
- Structured for maintainability and future enhancements

## Development Workflow

This project uses **Git Integration & Wix CLI**, a workflow that makes it possible to:

- Connect a Wix site directly to GitHub
- Develop locally in your preferred IDE
- Test updates in real time
- Push changes to the tracked branch
- Publish site updates efficiently

Any code committed and pushed to the tracked default branch will sync with the connected Wix site.

---

## Getting Started

To work with this repository locally, make sure you have the following installed:

- [Git](https://git-scm.com/download)
- [Node.js](https://nodejs.org/en/download/) (version 14.8 or later)
- [npm](https://docs.npmjs.com/downloading-and-installing-node-js-and-npm) or [yarn](https://yarnpkg.com/getting-started/install)
- An SSH key connected to your GitHub account

### Setup

1. Clone the repository
2. Open the project in your favorite IDE
3. Install dependencies if needed
4. Connect to your Wix development workflow
5. Start editing and testing locally
6. Commit and push changes to publish updates
